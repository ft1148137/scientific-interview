# 建筑与工程访谈资料

适用：土木校招、工程项目管理；只记录已提供证书与审批事实。

使用共同规则见 [行业索引](index.md)。先读原稿、JD 与已有经历，只从下列候选问题中挑尚未回答、最能改变匹配判断的 1—3 个；不是固定问卷。

## 校招（campus）

- 图纸、算量或进度计划属于课程设计、真实实习还是现场观察？
- 本人读图、计算、记录哪些部分，教师、组员或工程师如何复核？
- 现场是否承担资料记录责任，有无签字审批权限；证书事实有哪些材料？

回答判断示例：模糊：负责工程算量与现场管理。可用：基于教师提供的课程图纸计算工程量，现场仅观察，没有工程签证或验收权限。

## 社招（experienced）

- 本人、业主、承包方、监理和分包各自负责什么，谁最终审批？
- 金额是合同签约、审定结算还是到账回款，进度/成本成果的口径和范围是什么？
- 证书持有、注册状态和有效期分别有哪些证明；未知部分如何保留？

回答判断示例：模糊：完成项目结算并具备有效注册资格。可用：本人组织结算资料初审，金额指合同额；最终审批与注册有效性均未提供证据。

## 保存与停止

facts.responsibility_boundary 区分记录、初审与最终审批；credentials.registration 不由证书名称自动推断。

已确认的范围足以形成真实表述即可起草；用户回答“没有”“未知”“不便披露”时不要逼问数字。没有实际做过的内容不写入经历。字段按 [事实限定与资质](../facts.md) 选择，允许全部省略。
