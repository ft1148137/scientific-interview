打包工具将源码 ZIP 与 SHA-256 清单写入 `data/releases/`。它只接受指定源码目录和根文件，按 Git 候选文件打包，遇到常见敏感内容或异常文件会失败；CI 已接入同一检查。清单包含逐文件哈希与整个 ZIP 的哈希，便于核对发布内容。

自动检查使用启发式规则，无法识别所有个人信息或图片内容。以后新增样例、截图、字体或历史提交时，需要重新人工检查，不能把本次结论当作后续版本的保证。私人档案不要强制加入 Git，也不要通过完整工作目录压缩包发布。
